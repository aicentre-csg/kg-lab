# Knowledge Graphs Research Lab — Jekyll site

A lightweight, editable Jekyll site designed for GitHub Pages. It uses the supported `minima` theme with a small custom stylesheet; no JavaScript or build step is needed to edit content.

## Quick start: publish on GitHub Pages

1. Create a GitHub repository, for example `knowledge-graphs-lab`.
2. Upload the contents of this folder to the repository's root (not the ZIP file itself).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish. Your site will normally be available at `https://YOUR-USERNAME.github.io/REPOSITORY/`.

If you use a user/organisation site repository named `YOUR-USERNAME.github.io`, the URL is `https://YOUR-USERNAME.github.io/`.

## Important: customise before publishing

- `_config.yml`: update the title, description, email, social links and institution details.
- `_data/members.yml`: add group members and profile links.
- `_data/research_lines.yml`: edit the research themes.
- `_data/projects.yml`: add projects. Set `featured: true` to show a project on the home page.
- `_data/publications.yml`: add publications; newest years are shown first.
- `assets/css/style.scss`: change colours, typography and layout.

The people, projects and publications files contain clearly labelled example entries. Replace or remove these before the site goes public.

## Adding a profile photo

1. Create `assets/images/`.
2. Add the image, e.g. `alex-smith.jpg`.
3. Set `photo: /assets/images/alex-smith.jpg` in that person's entry in `_data/members.yml`.

## Updating content

Most updates are simple edits to the YAML files in `_data/`. Keep the indentation consistent and quote text containing YAML punctuation such as `:`. Commit changes to `main`; GitHub Pages rebuilds the site automatically.

## Preview locally (optional)

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Open the local address printed by Jekyll, usually `http://127.0.0.1:4000`.

## Notes

- The design is responsive and uses semantic HTML generated by Jekyll.
- No PHP or client-side JavaScript is required.
- `baseurl` is empty by default; GitHub Pages project sites generally work with an empty `baseurl` in this setup, but if you customise the URL or use a project-specific path and encounter broken links, set `baseurl: "/REPOSITORY"` in `_config.yml`.
- The lab name and all example content are placeholders and can be changed without editing the layout.
