# Knowledge Graphs Lab website

GitHub Pages/Jekyll site for the Knowledge Graphs Lab at the AI Centre,
City St George's, University of London.

## Updating the site

- Edit `index.html` for people, research lines, and projects.
- Add BibTeX records to `publications.bib`.
- Replace `assets/images/kg-lab-logo.svg` if the logo changes.
- Keep `baseurl: "/kg-lab"` in `_config.yml` for the current project-site URL.

The bibliography is loaded in the browser without unsupported Jekyll plugins.
